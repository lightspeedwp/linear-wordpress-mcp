# Assets

Static files and resources used by the project.

## Contents

- **Design assets** - Logos, icons, and visual materials
- **Templates** - Reusable configuration and code templates
- **Data files** - Seed data, fixtures, and reference datasets
- **Media** - Images, videos, and other media files

## Usage

Assets in this directory should be:
- Referenced by absolute paths from the project root
- Checked into version control
- Documented in the file or parent skill/script that uses them

See parent documentation for specific asset requirements.
