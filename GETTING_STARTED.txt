================================================================================
  ENVIRONMENT SETUP
================================================================================

You need 4 environment variables:

1. LINEAR_API_KEY
   Get from: Linear Settings → API → Create personal API key
   Example: lin_api_abc123xyz...

2. WORDPRESS_REST_API_URL
   Format: https://yourdomain.com/wp-json/wp/v2
   Example: https://myblog.com/wp-json/wp/v2

3. WORDPRESS_AUTH_USER
   Your WordPress username
   Example: admin

4. WORDPRESS_AUTH_PASSWORD
   Application Password (NOT regular password)
   Create in: WordPress Admin → Users → App Passwords

See SETUP_GUIDE.md for detailed credential retrieval steps.

================================================================================
  TROUBLESHOOTING
================================================================================

❌ Linear client not connecting?
   → Check LINEAR_API_KEY in .env

❌ WordPress returns 401 (Unauthorized)?
   → Use Application Password, not regular password
   → Verify WORDPRESS_AUTH_USER

❌ WordPress returns 404?
   → Verify REST API URL format
   → Test: curl https://yourdomain.com/wp-json/wp/v2/posts

❌ Tools not showing in Claude?
   → Restart Claude completely
   → Check MCP connection status
   → Verify environment variables are set

See SETUP_GUIDE.md#troubleshooting for more solutions.
